English is the preferred language for maintained documentation. French-only reference documents remain where there is no complete English equivalent, including the [architectural catalog](CATALOGUE_ARCHITECTURE_FR.md), [V2 usage guide](V2_ATELIER_FR.md), [Namebench integration](NAMEBENCH_TOPONYMS_FR.md) and [inhabited-region design](DESIGN_REGIONS_HABITEES_FR.md). The illustrated atlas retains its bilingual publication assets.

Dated studies and proposals describe their stated scope and date, rather than guaranteeing current implementation. AI instructions, session notes, reviews, diagnostic captures and validation campaigns are local working material, excluded from Git. Published illustrations, attribution, scientific references, reproducible fixtures and their required metadata remain versioned with the documentation or code that uses them.
