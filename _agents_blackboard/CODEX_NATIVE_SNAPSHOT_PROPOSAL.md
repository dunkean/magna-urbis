## Capture and selection

The existing test-only `Recovery` now owns a `native_snapshot_recovery::Recorder`. One hook after the successful principal resolver-result match observes the exact `ResolvedArchitecture`, before later shape/admission/native-entry changes. It covers shared initial-target, legacy-dimension, source-fallback and missing-simple-family resolutions. Metrics attach to the existing attempted-style journal: execution order, body area/target/error, actual primary levels/range, layout/composition rank, actual wealth/seed and nominal dimensions.

Only **one geometry snapshot** is retained. Each covered, conforming result competes by relative target error, then original execution order. A better result releases the previous snapshot before cloning the real new result into an `Arc`. No native preparation, source draw or admission outcome participates in selection. Journal metrics are small and inherit the already bounded ordinary source-resolution sequence; no extra geometry history accumulates.

Eligibility keeps automatic inspired domestic/mixed, matching pack/mode, original unpinned/default overrides, size 1/angle 0, enabled fitting, finite target, no exact/imposed footprint and **no explicit minimum-candidate contract**. Covered operators are existing Single/Strip rectangles with one ground/walled body and zero support height. Actual area must be within ±10%, actual levels inside the requested range, composition rank zero, and retained config seed/wealth equal the real request. Native preparation still decides whether a covered-looking operator truly has supported foundation/entry.

## After a complete ordinary refusal

The private pilot caller runs only after `plan_one_initial_with_recovery` completes every ordinary pass and final terrain recovery with an error. It reuses the chosen snapshot directly: **zero additional source resolutions or layout constructions**, one `PreparedPlan::with_native_entry` graph preparation, then at most four existing `frontage_poses_prepared` poses and normal admission. The same prepared native graph is cached for all poses. No alternate doors, resized assembly, constrained synthesis, arbitrary orientation pool or second snapshot/source follows a failure. Previously admitted results never enter this route.

Counter names distinguish source resolution/layout construction (both zero) from the one allowed native structural preparation. Ordinary roof admission remains cartographic; detailed native exterior replay is a separate proposed check. The module contains no calls to source resolvers, `build_layout`, dimension adapters or alternate-entry helpers.

**Coverage limit:** platform retry resolutions, terrain-rebuilt geometries and adapted internal candidates are not captured by this first tranche. They retain journal entries without snapshot metrics. No covered conforming snapshot means only that this experiment has none; it is not programme or physical impossibility. No third-party minimum witness or export is used.
