# Native parent batch v1: automatic city stream (proposal)

Status: isolated implementation reserved; no production edits or agent builds. Root validates. Current backend17/frontend16 integration is the root-verified selected-parent contract, not automatic city generation (native-assembly-product-root-proof-v1/root-verification.json). Core/Opus is out of scope.

## Wire and authority

New capability `houses.native-parent-batch-1`, with the existing pair and Std capabilities. Old `/houses/plans`, plan version, Single archives/imports and API stay unchanged. New local POST routes `/houses/plan-parent-batch`, `/houses/unpack-parent`, `/houses/realize-parent`; matching WASM functions `plan_parent_batch_json`, `unpack_parent_json`, `realize_parent_json`. Fourth route `/houses/unpack-parent-batch` / `unpack_parent_batch_json` takes `{schema_version,archives}` max64/24MiB and returns `{schema_version,plans,counts}` atomically, with no generation. All four decode original raw bytes with the existing scoped Std reader, before any historical Value parser.

Input `ParentPlanBatchRequest { schema_version: "native-parent-batch-1", batch: PlanBatchRequest(schema_version="1"), prior_occupation: { land_parts: Surface[], roof_parts: Surface[] } }`. Context is mandatory, possibly empty, spatially complete for cadastral/buildable/roof/access bounds, never camera-limited or truncated. Parts are exact immutable leaves, without parent, archive or city graphs; land and roofs remain separate.

Output `ParentPlanBatch { schema_version, generator_version, parents: ParentRecord[], refusals, open_spaces, materials, counts }`. A `ParentRecord` has `{plan, archive, attempt: AssemblyAttemptReport|null}`. `NativeParentPlan` has serde `kind` tag: `single { programme: ArchitectureProgramme|null, building: PlanBuilding }` or `assembly { assembly: RetainedNativeAssembly }`. Each admitted request produces exactly one parent, with the programme once; member plans never duplicate it. Counters: `requests`, `admitted_parents`, `single_parents`, `assembly_parents`, `physical_members`, `refusals`, `open_spaces`. Parent + refusal + open counts equal request count; physical members are separate.

`NativeParentArchive {format:"native-parent-archive-1",sha256,payload}` is packed natively BEFORE transport. It covers exact world Single geometry/access as well as groups, using retained f64 bits. Unpack returns the authoritative tagged plan; an adjacent decimal view is never import authority. Integrity checksum is not an authorship signature. `RealizeParentRequest {parent: NativeParentArchive, interiors:boolean}` returns tagged `single {building_id,ground_z_m,architecture:HouseBatch}` or `assembly {assembly:RealizedNativeAssembly}`. Actual native realize, atomic member failures, no source resolver or frontend reconstruction.

## Two physical phases

1. Finish the existing legacy PlanBuilding pipeline for every request (the `single` wire tag means one legacy parent, potentially several native bodies, not a Layout::Single claim), including native minimum, final entrance, incumbent growth and deferred need continuation, within its existing budgets. The new route supplies a separate internal typed context. Its common admission guard must check COMPLETE land (bodies/courts/native structures/passages/public paths) versus prior roofs, and new roofs versus prior land and earlier finalized Singles. Rejected candidates continue ordinary scheduled poses/fallbacks; no extra draw or trial. A final defensive qualification is additional, never a substitute. A continuation failure keeps its still-valid incumbent. Original neighbors remain intact; roofs are not injected as fake land neighbors.
2. Only after phase1 finishes, traverse admitted parents in original request order. For each covered compound attempt, reserve EVERY other finalized Single in this batch, including later requests, and replace each earlier successful group reservation with its actual members, shared context and circulation. Add complete preceding-batch land/roof leaves. Call the typed in-memory pair constructor BEFORE any JSON roundtrip. One bounded pair attempt per parent; source/variant/seed/non-dimensional parameters and old portal stay intact. Failure returns the entire exact Single. No hidden source query, redraw, wider door or relaxed physics. Both roof/land directions qualify all commits.

The parent owns public circulation and internal cap graph, programme and union-of-real-level outcome. Members own actual source/compact archive, pose, ground and native portal. Gross floor is measured; useful space and housed households remain unknown. Requested household counts/population/mass wishes never change or become delivered capacity.

## Bounded stream, compatibility and evidence

At most64 parents/128 members per call;24MiB native input,32MiB raw scoped decode,64MiB response,4096 surfaces AND polygons,262144 TOTAL geometry vertices including access/party segment endpoints, with administrative errors before unions and no truncation. The Std codec separately caps262144 float slots and64MiB rewritten bytes; two coordinates per vertex mean these maxima are NOT simultaneously reachable. The client counts every JSON numeric leaf conservatively against the slot cap and all source/context geometry before fixing its canonical prefix. Prior occupation has a distinct owner domain and is NEVER excluded by a colliding request-id string. Two transport trees and archive/view copies are real costs; these are not heap/time guarantees. Only bounded batch native graphs are retained. Frontend holds the necessary complete leaf spatial index for preceding batches, not all native parent graphs, and cold chunks retain parents atomically with member indices. Full lightweight overview/member selection must use real members.

Partition is part of generation identity: canonical prefix up to64/input-byte budget, no output-budget retry that silently splits a batch (phase2 depends on peers). Output failure aborts publication and keeps the previous city. Request cancellation/epoch/ACK/backpressure remain transactional. Fresh capabilities gate the actual CityBench stream; this is not a second selected-parent modal. Older engines use the explicit legacy path without claiming compounds.

Proofs prepared for root: same typed/Std inputs with phase2 off/on to isolate geometry changes; separately archive old-decoder/new-Std differences without normalizing them. Tests must exercise real in-memory batch assembly, shared batch later-incumbent reservation, parent/member counts, parent archive and atomic realize, growth/minimum/continuation roof guards, page1 group roof-only -> page2 Single/path guard, complete prior member/context insertion, resource errors, cancellation/legacy compatibility. Synthetic positive is labeled separately from all real fixed cases. No city gain/capacity is claimed before root's real replay.

Implementation note: the admission context is synchronous scoped RAII, non-Send/non-reentrant and request-identity checked; no unsafe or state persists beyond the call. It commits only final chosen plans/continuations and remembers bounded geometry signatures to prove the retained result passed the guard. Future parallelization must explicitly install/pass context per worker.
