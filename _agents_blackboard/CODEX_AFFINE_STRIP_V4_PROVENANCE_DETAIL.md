## Engine-owned capability

The new test-only `engine::retained_strip_rebuild` module records the **actual seed used by the successful non-minimum Atlas/unit-0 resolver**. It does not reconstruct a seed from request text. One immediate event per thread is cleared before each resolution/draw attempt; the snapshot collector consumes it immediately and retains an opaque capability alongside its single geometry Arc. There is no unbounded registry or public archive/DTO field.

The capability hashes schema/generator/config/recipe, every retained parameter and the complete geometry/context/entrance. Planner diagnostic prose is intentionally excluded. A changed seed, wealth, non-dimensional draw or geometry fails before reconstruction. Canonical minimum results never mint this capability. `selected_draws` has a test-only entry counter, permitting assertions that fitting, owner rebuild and both detail replays perform no additional source draw.

The adapter now requires that capability. The engine helper independently checks source/physical axis bounds, active-infill exclusion, supported Strip topology and the unspent one-construction budget. It copies actual parameters, changes only W/D, and invokes `build_layout` once using the captured seed. It checks config, all non-dimensional parent/body parameters, levels/role/component/z, and non-geometric feature/context metadata exactly. No resolver or source draw is called. The existing native preparation, exact admission, first frame, four scalar corners and physical guards remain unchanged.
