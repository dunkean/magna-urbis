## Files and protocol

New `urbanBuildingDerivedCache.ts`: versioned optional sidecar; manifest authenticates parent/source fingerprints, per-chunk native SHA/progress and child SHA/encoded-byte count, totals and complete/unknown origins. JSON codec preserves negative zero; parsed exact child surfaces are interned to retain the existing alias-dependent ground/detail behavior. No native plan/archive/levels/parameters or queries are stored. Derived chunks≤32MiB and≤64native records; this encoded budget is not measured JS heap.

`urbanBuildingChunkIndexedDb.ts`: schema2 adds only derivedScenes/derivedChunks/derivedOrigins. Existing native stores and data remain; blocked-open and versionchange behavior stay explicit. Every cache write has a unique cacheId; transactions reject stale writers, and old aborts cannot delete the replacement epoch. Derived commit requires the matching already-committed native parent inside its transaction. No active native pointer is changed by derivative operations.

`urbanBuildingChunkStore.ts`: stage owns the optional sidecar. It projects the already-decoded authenticated chunk once; native append finishes first, derivative append finishes before ACK, failure only disables/discards the cache. Native CAS remains the commit point; derivative commit comes afterward and cannot undo native durability. `appendStored` still writes exact original native payloads; export/import format and native fingerprint content are unchanged. Import produces a visual cache with origins unknown when original worker sites are absent.

`urbanScene.ts`: passes the actual ordered projected sites into stage.append, then reuses the stage's last projection for preview. It does not disable retainSites or remove any consumer. A real site id→offset/parcel/cache-record index is written in the sidecar; accepted recordIndex is never treated as site offset.

`urbanColdCitySession.ts`: restore validates the native manifest then loads/authenticates sidecar children, without any native chunk read on a hit. Missing/stale/corrupt/partial/quota cache falls back to the existing serial native traversal; it builds a replacement derivative as chunks pass through and does not publish partial cartography. Native corruption still refuses. Full visual arrays remain resident, explicitly O(N). No original sites can be reconstructed from an archive: such rebuilds carry origins unknown unless real original site visuals are supplied.

`urbanSiteStore.ts`, `terrainUrban.ts`: live worker query can optionally confirm its known original offset via authenticated durable lookup before the true unit constraint read. Cache lookup failure falls back only to the already-live original site metadata, never a projected constraint. Restore exposes all cached sites for existing roles/landmarks/comparisons using an UNBOUND read-only store; URL/revision from DB is never reactivated. Style edit guards remain unavailable as before when current native origin is absent. Cached target text is labeled a conserved site request rather than falsely current. World translations move visual/site coordinates only; original offsets/local archives are untouched.

`urbanColdCityEdit.ts`: forwards optional sidecar through its guarded backend and preserves original site slices when available. All native neighborhood/material/archive/CAS/rollback logic and exact untouched payload copies remain. The full-city authenticated native copy cost remains; A does not claim to solve that edit CPU cost.
