# Cold accepted-plan projection — 3D consumer

2026-10-23. `City3dOptions.getProjection?(): NativeBuildingProjectionScene | undefined` is implemented and takes precedence over legacy getScene, including an empty projection. Citybench/terrainUrban bindings remain root's work. No Rust/Cargo/native/server/browser was invoked for this change.

The geometry/pass accepts the typed union `Building3dVisual = PlacedBuilding | NativeBuildingProjection`. A projection remains the original DTO: no cast/fabricated PlacedBuilding, native volumes, archive or guessed gable. It draws a display-only extrusion of the exact accepted body outline and a horizontal cap of the exact roof outline at native ground + recorded height. Holes are retained. The same triangle iterator is used for rendering and picking. Selected projections are labelled « volume cartographique »; these display surfaces do not certify native physical walls/roofs.

Native detailed exteriors still come from the shared controller. The 3D consumer requires exact indexed contour references plus ID/parcel/recipe/variant/function/ground identity before installing a projection's cached detail. Dropped cache entries restore the original projection. The legacy local realizer is guarded against projection scenes before module import and dispatch. Source epochs guard legacy module loading, queued work and replies; old swaps are cleared on source rebuild. Dispose unsubscribes and cancels callbacks.

The projector now extracts exact lightweight child data for the existing physics-adjacent display consumers: `occupation_surfaces` is accepted footprint + circulation + structural feature surfaces; `ground_constraints` is accepted footprint/ground plus existing structural foundation footprint/z_max. These are the previous forest/ground inputs, not inferred feature bearing data. No feature objects, native parents, meshes or archives enter the DTO. The 2D draw contract remains unchanged. A projection display scene retains `occupationBuildings` separately, so a visual exterior swap or later full display rebuild cannot silently replace accepted terrain/forest inputs. Bridges/walls are appended to both sets. Legacy scenes omit that optional field and keep their old behavior.
