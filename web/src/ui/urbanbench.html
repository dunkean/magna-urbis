Les décors sont des cartes de Terrain Bench (relief, eaux, settlements, routes) exportées avec « Export decor » ou en lot par node scripts/export_decors.mjs. Le raster transmis à Rust est exactement celui de Terrain Bench : un lieu du décor, avec les routes du décor et la graine de la carte, donne les mêmes quartiers que dans Terrain Bench.

Les étapes Quartiers et Parcelles sont celles de Terrain Bench (même code, mêmes paramètres, même lien). Avec npm run dev:terrain, une modification de rust/crates/core/src/urban recompile le WASM et recharge la page.
